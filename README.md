# opencode-hi-suite-test

Basit bir e-ticaret sepet ve indirim hesaplama kütüphanesi (OpenCode-Hi GitHub otomasyon testi için örnek proje).

## Özellikler

- Toplu alım indirimi (`10` ve üzeri adette `%10` indirim)
- Kupon kodu desteği (`SAVE20`)
- Kargo ücreti hesaplama (`100` TL altı siparişlerde `15` TL kargo; boş sepette `0` TL)

## Testleri Çalıştırma

```bash
npm test
```
